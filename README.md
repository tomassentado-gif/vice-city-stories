# Vice City Stories

An original browser-based 3D open-world game prototype.

## Play locally
Open `index.html` in a modern browser with an internet connection. Three.js is loaded from jsDelivr.

## Controls
- **WASD** — move / drive
- **Shift** — run
- **E** — enter or exit the yellow car
- **R** — reset your position

## Current prototype — v10.1
- Procedural 3D coastal city with animated ocean and day/night cycle
- Third-person character, drivable vehicles, traffic and pedestrians
- Detailed vehicle bodies and architectural facades
- Garage, vehicle selection and paint customization
- Apartment, delivery side job, vehicle save/load and city guide
- Mission checkpoints, minimap and HUD

## Deployment
GitHub Actions deploys the repository to GitHub Pages on every push to `main`.
