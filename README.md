# Vice City Stories

An original browser-based 3D open-world game prototype.

## Play locally
Open `index.html` in a modern browser with an internet connection. Three.js is loaded from jsDelivr.

## Controls
- **WASD** — move / drive
- **Shift** — run
- **E** — enter or exit the yellow car
- **R** — reset your position

## Current prototype
- Procedural 3D coastal city
- Third-person character
- Drivable vehicle
- Mission checkpoints and reward
- Minimap and HUD
- Responsive interface

## Deployment
GitHub Actions deploys the repository to GitHub Pages on every push to `main`.
